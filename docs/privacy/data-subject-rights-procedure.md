# Data Subject Rights Procedure

## Scope
Process for handling export and erase requests.

## Steps
1. Verify requester identity.
2. Locate all user-linked data across primary systems.
3. Produce export package and secure delivery.
4. Perform erasure workflow where legally allowed.
5. Log completion in audit trail.

## Rehearsal Checklist
- [ ] Identity verification documented
- [ ] Export package generated
- [ ] Erasure simulated
- [ ] Completion time recorded
- [ ] Evidence stored in `docs/qa/`
